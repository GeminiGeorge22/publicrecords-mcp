# Public Records Postman collection

Import [`Public-Records-Apify.postman_collection.json`](Public-Records-Apify.postman_collection.json) into Postman (File → Import). It covers 17 Public Records Actors (the Skool Actor is omitted).

Set the collection variable `APIFY_TOKEN` to your own Apify API token after import. The published file ships with that variable empty and contains no secrets. Requests run on your Apify account (pay-per-use; Apify has a free usage tier).

OpenAPI sources: https://huggingface.co/datasets/Publicrecords/apify-actor-openapi

Author: Public Records.

A hosted Postman public workspace was not published this pass: Postman's Free plan allows public workspaces, but creating one with the Grok Bot email needs an email OTP that could not be completed here. Anyone can still import this collection.
