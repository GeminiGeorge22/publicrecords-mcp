# Public Records beta testers

Author: **Public Records**

We want real users to run the Public Records Apify Actors and MCP servers on **their own** accounts and tell us what works, what breaks, and what you needed that isn't there yet.

This is a feedback program, not a star campaign. **GitHub stars are optional and are never rewarded.** If a repo helped you, you are welcome to star it. The incentives below are only for useful feedback: a bug report, a written review, or a concrete use case.

## What to test

Pick any Public Records Actor and run it on **your own Apify account**. You do not need our token, and we will never ask for yours.

- **Apify Store:** [apify.com/publicrecords](https://apify.com/publicrecords)
- **MCP servers** (Cursor, Claude Desktop, and other MCP clients): this repository. The one-paste pin and client setup are in the [README](./README.md).
- **Agent Skills** (Claude Code, Codex, Copilot, Cursor, Gemini CLI, Kiro): [publicrecords-skills](https://github.com/GeminiGeorge22/publicrecords-skills)
- **Automation recipes:** [publicrecords-automation-recipes](https://github.com/GeminiGeorge22/publicrecords-automation-recipes)
- **Dify plugin:** [publicrecords-dify-plugin](https://github.com/GeminiGeorge22/publicrecords-dify-plugin)

A small run is enough. Try the Actor or skill you actually need: a Grants.gov search, a SAM.gov or USAspending pull, a UK or EU tender lookup, a council meeting, a job-board scrape, company social links, and so on. Tennis Scores API is an Apify Actor only (no hosted MCP endpoint yet); you can still test it through the API or the [examples repo](https://github.com/GeminiGeorge22/publicrecords-tennis-scores-api-examples).

### Cost, honestly

Actor runs are billed to **your** Apify account on Apify's pay-per-event or platform pricing. We do **not** give testers free Apify credits, coupons, or reimbursements. Apify's free plan includes monthly compute credit that is typically enough for small test runs; check the current free-tier allowance and each Actor's Store page for live prices before you start. If you stay within a few small runs, you should not need a paid Apify plan just to try this.

Never paste a token into a GitHub issue, a discussion, or an email.

## How to report

1. **Bug** — open a GitHub issue with the Bug form in this repo.
2. **Beta feedback** (what you tried, what worked, what you want next) — open an issue with the Beta feedback form.
3. **Introduce yourself** — comment on the pinned Discussions post, [Beta testers: introduce yourself / what are you using it for](https://github.com/GeminiGeorge22/publicrecords-mcp/discussions).

Useful reports include: the Actor or skill you ran, the client (Cursor, Claude, a script, and so on), a short input (no tokens), what you expected, and what you got. Logs are welcome if they contain no secrets.

## What we offer for feedback

If you send useful feedback — a bug report, a review, or a use case — we will:

- Credit you in the **Beta testers** section of this repository's README (and, if you want, in [publicrecords-skills](https://github.com/GeminiGeorge22/publicrecords-skills)), using the GitHub handle or name you choose.
- Give you first pick when we ask testers about new Actor or feature requests.
- Give you early access to new Actors before we announce them more widely.

These rewards are for feedback only. **We will never offer credit, access, or anything else in exchange for a GitHub star.** Please do not star the repos just because you are in the program, and please do not ask others to star them on our behalf.

## Star the repo if it helped

If you tried it and it saved you time, a star on [publicrecords-mcp](https://github.com/GeminiGeorge22/publicrecords-mcp) or [publicrecords-skills](https://github.com/GeminiGeorge22/publicrecords-skills) is a nice way to say so. That is optional. It is not required to join, and it is not part of the rewards above.
