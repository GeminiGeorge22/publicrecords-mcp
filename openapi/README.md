# OpenAPI 3.0.3 specs for Public Records Apify Actors

Machine-readable specs for 18 public Actors, generated 2026-11-24 from each Actor's published input schema. Hosted also as a Hugging Face dataset: https://huggingface.co/datasets/Publicrecords/apify-actor-openapi

Each spec describes `POST /v2/acts/publicrecords~<slug>/runs` and `POST /v2/acts/publicrecords~<slug>/run-sync-get-dataset-items` on `https://api.apify.com`. Calls use the caller's own Apify token (pay-per-use). Author: Public Records.

The Skool community tracker is omitted from this bundle.

See `index.json` for the file list. MCP: `https://mcp.apify.com?tools=publicrecords/<actor>` for Actors that have a hosted MCP / Standby or an Apify MCP tool listing. `tennis-scores-api` is an Apify Actor only (Standby/MCP is not built); use the REST paths in its spec, not an MCP endpoint.
